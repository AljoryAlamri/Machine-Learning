# ARTI205 Lab 2 - Short Summary

This lab focuses on exploring and analyzing a customer churn dataset using Python and Pandas. The dataset was loaded and inspected to understand its structure, columns, data types, and statistical characteristics.

The dataset contains 64,374 records and 12 columns. Data preprocessing checks were performed, including checking for missing values and examining the distribution of categorical variables such as Gender, Churn, and Subscription Type.

A workflow diagram was also created to represent the main steps of the machine learning process: Dataset Selection, Data Loading, Data Preprocessing, Train/Test Split, Model Training, Model Evaluation, and Results.
